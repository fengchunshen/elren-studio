# 《最后一单》AI 短剧工作流

原创都市悬疑样片：雨夜便利店里，顾客提前说出即将发生的事，试图阻止店员开门。第八次循环终于改变，敲门声却提前了。

目标为 **60 秒、9:16、两位角色、一个场景、12 个镜头**。提供完整剧本、人设、分镜及可导入 Elren Studio 的画布工作流。不是已完成的60秒视频。

## 文件

- `最后一单-工作流.zip`：项目与视觉参考图；直接导入此文件。
- `剧本.md`：逐镜动作、对白和声音。
- `人设与视觉规范.md`：两位角色、空间关系、光线和连续性。
- `分镜设计.md`：12镜时间表、景别、机位、画面、声音。
- `shots.json`：可复用的逐镜图片/视频提示词。
- `project.json`：37节点、60连线、4个命名分组；素材路径须通过ZIP导入解析。
- `assets/visual-reference.png`：实际 imagegen 生成的人物和场景参考板。
- `调试记录.md`：当前验证和未完成项。

## 导入

1. 打开本地工作台 `http://localhost:8081`，登录。
2. 新建独立项目，避免把原项目替换为本样片。
3. 左上角项目菜单 → 更多 → 导入项目，选择 `最后一单-工作流.zip`。
4. 等待显示“已保存”。左侧节点搜索可以按“林夏定妆”“01 杯子要倒了”“总分镜表”定位。

## 运行

工作流采用分阶段人工确认，不是自动遍历整图的调度器；连线代表实际输入依赖，批量生成前先验一个镜头。

1. **剧本**：已给出完整初稿。修改简报、剧本和人设；文字节点可选择当前可用文本模型继续润色。下游已有文字不会被上游编辑自动覆盖。
2. **定妆/场景**：06–08节点选择可用图片模型，分别生成林夏、陈默和空便利店，数量1。选择支持参考图片的模型；参考板中只取对应区域的身份与风格，输出单张画面。图片通过后再进入下一阶段。
3. **首帧**：先执行01首帧，再执行其余首帧。每镜已连接对应角色和场景；04双人镜头需要可接收至少3张参考图的图片模型。模型不支持时先输出双人合照作为统一参考，再调整该镜输入，不静默丢弃人物参考。
4. **视频**：选择支持图生视频/首帧的当前可用模型。每镜目标5秒、9:16，先按模型开放规格生成；若只支持更长时长，生成后裁至5秒。先完成01视频核对稳定性，再做其余11镜；失败只重试对应节点。
5. **剪辑**：12个视频就绪后选中时间线，点击“添加已连接视频”。按01–12顺序排列，每段裁成5秒；默认输出720×1280。可改1080×1920，但不等于源视频获得真实1080P细节。点击“合并到画布”并下载。
6. **声音与字幕**：按声音清单在剪辑软件配音、混音和叠字幕。小票上的“第八次 / 00:00”后期叠加；字幕建议不超过两行，每行14字左右，避开平台底部操作区。对白可跨镜剪辑以减少正面口型要求。

## 约束与检查点

- 锁定同一版定妆图后再批量生成。角色脸型、发型、耳钉、围裙和夹克不能漂移。
- 柜台在左、门在右后方，保持轴线。杯子镜头1被扶稳后始终完好。镜头8才锁门，门全片不开。
- 镜头6顶灯熄灭；7–12只保留冰柜冷光与门外路灯。各镜提示词已加入覆盖规则。
- 图片与视频提示词分别存放：前者只定义首帧，后者定义5秒内动作和运镜。
- 总分镜表供审阅；与独立生成节点不自动双向同步。改分镜后同步修改对应首帧与视频提示词。
- 时间线只新增尚未入轨的来源，不覆盖已有排序、裁切或已切分片段；重新生成的同源视频需手工决定是否替换旧剪辑。
- 模型字段留空，避免把不存在/未开放的模型写成可用。真实模型生成会使用当前账号额度；本项目文件导入本身不提交生成任务。
- 尚未生成的视频节点保持空结果，不用静帧、演示视频或假任务冒充完成。

## 重建与针对性检查

```sh
python3 examples/last-order/build.py
npx vitest run tests/last-order-workflow.test.js tests/node-io.test.js --maxWorkers=1 --minWorkers=1
```

`build.py`从可编辑的分镜源重建项目、剧本、分镜表及ZIP；不会调用模型。手工修改生成文件后再次执行会被源数据覆盖，应同时修改脚本内的源数据。

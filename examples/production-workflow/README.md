# 《最后一单》标准短剧制作工作流

可导入项目：`最后一单-标准短剧制作工作流.zip`。13个节点、19条实际连线，12个预填镜头。保留现有原创故事，按成熟制作方法重新组织；不自动提交模型任务。

## 参考依据

- [StudioBinder：How to Make a Shot List](https://www.studiobinder.com/blog/how-to-make-a-shot-list/)：从剧本拆解到镜头表，明确景别、机位和镜头顺序。对应本项目的剧本、人设场景、分镜表。
- [LTX Studio 官方教程](https://ltx.io/blog/ltx-studio-tutorial)：Elements 管理人物、环境等一致性资产；满意的静帧再做动画；Storyboard 排序并调整时长。对应本项目的独立定妆/场景资产、确认画面、逐镜视频及剪辑。

这是将上述制作方法适配到现有节点能力的工作流，不宣称复制了这些产品的自动化或所有功能。

## 执行顺序

| 阶段 | 实际操作 | 进入下一步的检查 |
|---|---|---|
| 01 剧本 | 编辑创作简报及完整剧本 | 明确人物目标、动作、对白、声音和结尾；本例为两人一景 |
| 02 人设与场景 | 分别编辑猫店员、兔顾客、便利店设定 | 固定外形、服装、性格、道具、空间轴线与灯光连续性 |
| 03 视觉资产 | 各自生成并选定两张定妆图、一张场景图；概念板仅供风格参考 | 人物形象和场景一致，再进入分镜；这是人工审片步骤 |
| 04 分镜 | 逐镜检查构图、景别、对白与声音，生成静帧，选中候选并勾选“确认此画面” | 镜头叙事成立、轴线和人物一致；确认图是视频的实际输入 |
| 05 生成视频 | 对应首帧自动读取；调整动作和运镜，生成、播放审片，勾选“选为输出” | 无明显形变、穿帮，动作和切点可剪；未确认画面时禁止生成 |
| 06 剪辑 | “添加已连接视频”，按镜头排序，调整入出点，再“合并到画布” | 先粗剪叙事和节奏，再完成声音字幕与最终检查 |

12镜×5秒是本例的初始镜头预算，不是所有短剧的固定规则。实际剪辑按表演和对白调整，增加可用素材或修改镜头时长后重新核算总时长。

## 数据与能力边界

- 人设和场景各有独立文本与图片节点，实际连入分镜；生成图会作为图像参考。现阶段同一分镜板共用连接的三项资产，每镜提示词明确使用哪名角色，不等同于逐角色身份锁定算法。
- 分镜与视频通过镜头 ID 一一关联，项目导入及另存模板时重映射节点身份。不能用同名镜头替代绑定。
- 图片确认、视频选片是两次不同的决定。修改上游剧本/人设后，人工更新受影响分镜并撤销旧确认，再决定是否重生成；不自动重写、不自动作废已有视频。
- 时间线只加入已选视频，重复同步去重并保留手工裁切。已导入片段不会因上游重生成而自动替换，需要人工核对版本。
- 内置时间线负责画面排序、裁切、拼接。配音、字幕、音乐、音效和小票叠字按后期交接单在外部剪辑软件完成；本项目不冒充已接入完整多轨声音制作。
- 新项目全部镜头为草稿，时间线为空。已有概念板注明来源，未复用旧首镜视频冒充这次人设定妆后的成片。

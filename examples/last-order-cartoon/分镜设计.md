# 《最后一单·雨夜来客》分镜设计

12镜×5秒＝60秒。对白可略跨镜，用听者反应镜头衔接。镜头6后只保留冷光与路灯。

|镜头|时间|景别与机位|首帧与动作|对白/叠字|声音|
|---|---|---|---|---|---|
|01|00–05s|特写 / 85mm / 固定|柜台上的白杯立在边缘，林夏袖口刚接近杯子，杯子尚未倾倒。 白杯缓慢倾斜，林夏的猫爪及时扶稳，动作一次完成，机位固定。|陈默（画外）：别碰。杯子会倒。|雨声；杯底轻响|
|02|05–10s|近景 / 50mm / 缓推|林夏站在柜台后，低头看向被扶稳的杯子。 林夏抬眼望向画面右侧顾客，眉头轻皱，镜头缓推。|林夏：你怎么知道？|冰柜低鸣|
|03|10–15s|中近景 / 50mm / 固定|陈默站在柜台另一侧，雨珠挂在夹克上，握着小票。 陈默看向左侧店员，再把视线转向右后方玻璃门。|陈默：十二点，别开门。|远处闷雷|
|04|15–20s|过肩 / 50mm / 固定|从陈默右肩后看林夏，柜台和白杯位置不变。 林夏轻轻后退半步，手留在柜台上，警惕看着陈默。|林夏：凭什么信你？|音乐开始低频脉冲|
|05|20–25s|近景 / 50mm / 固定|陈默抬眼看顶灯，嘴唇紧抿。 陈默轻抬食指提示等待，视线回到店员。|陈默：灯会灭。然后，你的手机会响。|低频声收紧|
|06|25–30s|中景 / 35mm / 固定|林夏位于暖光柜台后，冷光冰柜和玻璃门可见。 暖色顶灯熄灭一次，保留冰柜弱冷光；林夏肩膀轻颤，禁止全黑。|无对白|灯管啪一声；随后手机铃声|
|07|30–35s|俯拍特写 / 85mm / 固定|柜台上一部黑色手机，屏幕无可读文字，白杯位于画面边缘。 手机轻微振动，林夏猫爪停在屏幕上方，不触屏。|陈默（画外）：也别接。|手机铃声持续后切断|
|08|35–40s|中景 / 35mm / 固定|林夏站在玻璃门内侧，右手靠近门锁，门外仅雨和路灯。 林夏转动门锁，回头看向店内；不打开门，不出现门外人物。|无对白|锁舌咔哒；音乐暂缓|
|09|40–45s|近景 / 50mm / 缓推|陈默靠着柜台，握小票的手放松一些。 陈默长呼一口气，眼中短暂释然。|陈默：我来过七次。只有这次，你没开门。|雨声短暂变清晰|
|10|45–50s|极近特写 / 85mm / 固定|陈默手中白色小票摊开，占画面中部，纸面留空，兔爪为简洁圆润动画造型。 兔爪轻轻展开小票后停稳，纸面保持干净可叠字。|无对白；后期小票文字：第八次 / 00:00|纸张摩擦；一次心跳|
|11|50–55s|近景 / 50mm / 固定|林夏回到柜台附近，皱眉看向陈默，背景玻璃门保持同侧。 林夏察觉异常，目光从陈默的兔爪移到脸上。|林夏：那你为什么还在发抖？|音乐抽空；门外两下敲击|
|12|55–60s|近景 / 50mm / 极慢推|陈默侧脸近景，右后方玻璃门虚化，门外没有人形。 陈默骤然望向玻璃门，瞳孔紧张，最后半秒冻结式停顿，不切镜。|陈默：因为这次……敲门提前了。|第三下敲门；尾帧切黑|

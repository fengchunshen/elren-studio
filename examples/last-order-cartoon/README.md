原创二维赛璐璐悬疑动画，60秒、9:16、12镜。沿用“顾客预知下一分钟，阻止店员开门”的故事，角色改为猫店员林夏与兔顾客陈默。使用明确的动物耳朵、口鼻、爪子及简洁卡通轮廓；不引用真人版的人像图片。

## 导入和第一镜验证

1. 在工作台新建项目“最后一单｜卡通短剧工作流”。不要覆盖真人版项目。
2. 项目菜单 → 更多 → 导入项目，选择本目录ZIP，等待“已保存”。
3. 搜索“01 卡通首帧素材”，可以看到已提供的猫店员首帧。
4. 搜索“01 杯子要倒了 · 视频”：首帧已连接，模型绑定当前本地可用的Seedance 2.5，目标5秒，关闭生成音频。
5. 或打开总分镜表，点击第一镜：已填入同一张卡通首帧，可直接执行。**这两处是替代入口，只运行一处，避免重复生成。**
6. 正常结果应保持猫的身份、绿色围裙、杯子和便利店结构，只有杯子倾斜、猫爪扶正的小动作。验证视频可播放后再批量制作其余镜头。

如导入另一套部署后模型不可用，从菜单重新选择实际开放的模型；本包的模型ID仅对应本地已核对目录，不含账号或API密钥。

## 其余镜头

- 先用参考板生成猫店员、兔顾客、空场景三个视觉开发节点，再逐镜生成首帧。
- 所有首帧和视频提示词都明确指定二维赛璐璐拟人动物风格。保持猫耳、猫尾、兔耳、毛色、额发及服装一致。
- 第一镜也保留独立的首帧生成节点，供重新构图；它与已经提供的首帧素材分开。使用新生成图时，手动替换视频的首帧连接或分镜首帧。
- 单镜首帧选好后再运行视频；不要直接对没有参考图的其他分镜批量执行文生视频。
- 视频完成后，在剪辑时间线点“添加已连接视频”，顺序01–12，各裁为5秒。
- 台词配音、雨声、灯灭、电话与敲门音效，以及小票文字“第八次 / 00:00”在后期剪辑中加入。
- 总分镜与独立生成节点不自动双向同步，替换提示词或首帧时更新选用的执行入口。

# 前端设计与交互规范

**每次设计、新增、修改或评审前端页面、组件、样式、文案及交互前，必须先完整阅读本文件。**

这是项目的前端规范统一入口，适用于新页面和存量改造。用户当前明确要求优先；本文件记录截至 2026-09-08 的设计方向和返工教训。旧实现不是设计标准，不能因为代码中存在某种写法就继续照搬。

## 1. 开始设计前

1. 阅读本文件，再检查相关业务组件、`src/components/ui` 和 `src/index.css`，确认现有行为与数据来源。
2. 用户提供截图、视频或已打开的参考页时，先看清楚触发方式、默认、悬浮、展开、关闭与操作结果。不能只学图标、圆角、颜色。
3. 参照参考产品的内容优先级与交互：作品是主体，工具退到背景，操作跟随上下文，模式切换有明确反馈。不能把参考页面的功能名直接做成无效按钮。
4. 明确本次功能的实际能力和必要状态。已有标准组件优先复用，专用交互在业务层组合。不清楚的功能先查参考行为和代码，不能把“重置”猜成清空，把“批注”猜成居中表单。

## 2. 组件库与选择规则

基础 UI **统一使用项目内的 shadcn/ui 源码组件**，底层交互由 Radix 处理；图标使用 `lucide-react`，通知使用 Sonner。

- 组件入口：`src/components/ui`；业务组合：`src/components/editor`、`src/platform` 等。
- 注册配置：`components.json`，当前为 `new-york`、JavaScript/JSX、CSS variables、Lucide。
- 技术基线：React 18、Tailwind CSS 3，版本以 `package.json` 为准。添加组件前检查兼容性，不直接用面向 React 19 / Tailwind 4 的生成代码覆盖现有源码。
- shadcn 是项目维护的组件源码，不是一个运行时整包。依赖已安装、导入数量多，都不能证明控件真正使用了它的交互能力。

| 场景 | 使用的组件或实现 | 约束 |
| --- | --- | --- |
| 普通按钮、图标按钮 | `Button` | 使用现有 variant 和 size；图标按钮提供 `aria-label`，必要时配 `Tooltip`。 |
| 文本输入、长文本、标签 | `Input`、`Textarea`、`Label` | 保留语义、键盘和焦点行为。 |
| 普通表单的简单下拉选择 | `NativeSelect` | 使用现有封装，保留原生表单契约。画布生成面板中的模型、数量使用 `DropdownMenu`；画质、比例、时长组合进 `Popover`，避免原生系统菜单割裂画布。 |
| 复选、开关、滑动数值 | `Checkbox`、`Switch`、`Slider` | 遵守受控值契约，显示状态与实际行为一致。 |
| 空白画布右键菜单 | `ContextMenu` 及其子菜单 | Radix 负责关闭、子菜单过渡、键盘、Portal 和边缘避让。 |
| 点击入口展开的操作菜单 | `DropdownMenu` 及其子菜单 | 用于更多、模板管理、连接端口等操作菜单。 |
| 锚定入口的侧栏、就地编辑 | `Popover` | 根据任务选择模态性；画布侧栏与评论输入使用非模态浮层。 |
| 简短操作提示 | `Tooltip` | 不代替必要入口，不再叠加原生 title 形成双重提示。 |
| 独立详情、配置、表单 | `Dialog` / `EditorDialog` | 任务确实需要时才使用，提供标题、关闭和焦点返回。 |
| 独立侧边任务区 | `Sheet` | 不能因为已有 Sheet 就把所有画布入口改成抽屉。 |
| 容器、普通业务表格 | `Card`、`Table` | 不强行给图库套上整卡背景和悬浮效果。 |
| 侧栏、图库、弹窗内容滚动 | `ScrollArea` | 使用 shadcn/Radix 浮层滑块；文本框、画布节点和表格等原生滚动区由全局主题样式统一。 |
| 成功、失败、操作反馈 | Sonner `Toaster` / `toast` | 简洁说明结果，避免重复打断。 |

维护边界：

- `components/ui` 只负责通用控件，不导入服务、平台业务或 `App.jsx`；业务差异在业务组件组合。
- 优先使用 variant、组件组合和布局类，不写全局 `button:hover`、`input`、`svg` 覆盖，不复制整套基础控件。
- 特定外观只在对应组合内局部调整，保留可访问性。去掉整卡悬浮应拆分封面与标题，不能破坏全站 Button。
- 画布、节点、连线、图片对比、蒙版、分镜编辑器属于专用交互，不硬套通用表格或表单；无媒体模板可用 SVG 展示实际节点结构。
- 隐藏 `input[type=file]` 保留原生 FileList/ref 契约；`main.jsx` 的崩溃兜底可以保留独立原生 HTML。
- 存量手写提示、同步 `alert/confirm/prompt`、局部旧颜色仍有待迁移。相关改造时逐项处理，不宣称全站已完整迁移，也不在无关任务中全局替换。

## 3. 设计准则与风格

### Elren Studio 品牌

- 平台对外名称统一为 **Elren Studio**，覆盖画布、工作空间、登录、启动提示、浏览器标题和导出文件名。
- 品牌按场景展示：工作空间、登录等页面使用单行 `ElrenBrand`（渐变图形＋**ELREN** 矢量字标）；画布左上角仅使用 `ElrenMark`（图形＋分隔线＋项目名＋下拉箭头）。项目名在窄屏仍显示并按需省略，不堆叠完整品牌和项目名，不添加 **STUDIO** 小字。
- 字标按用户提供的轮廓重绘为路径，不用普通字体近似，也不把参考 PNG 当成矢量文件。
- 图形参照用户图 1 保留蓝、青、粉叠合结构。矢量源文件为 `src/assets/brand/elren-mark.svg`、`elren-wordmark.svg`，品牌组件位于 `src/components/brand/`；不在通用 UI 控件里加入品牌逻辑。
- **已确认的加载动效（2026-09-11）**：64px 图形按 **ELREN 原轮廓 → 实心圆 → 圆角方形 → ELREN** 循环，约 3.44 秒一轮，关键形态有停顿。加载画面只展示图形，状态文字供辅助技术读取；常规品牌展示保持静态。
- 图形内部采用蓝紫、冷白色面的柔和融合与细微纹理，并使用独立节奏持续流动，轮廓停留时仍能看见颜色变化。**全屏加载背景固定纯黑 `#000`，不使用渐变或色场，不随深色、浅色、Solarized 改变。** 区域内加载只显示动效图形，沿用所在区域的背景。
- `ElrenLoadingProvider` 汇总账号连接、项目列表、编辑器代码和项目快照的真实等待状态，共用一个加载层；阶段交接不重播。完成后 180ms 淡出并立即恢复操作，不为了播完整动画延迟内容。失败要结束等待并展示既有错误反馈，不能掩盖失败或改写项目数据。
- 首屏 HTML 由 `scripts/elren-boot-splash.mjs` 从同一组件生成，资源内联；JS 加载前即可显示。减少动态效果时使用静态原 Logo，取消流动、形变及退场动画。
- 用户否定过摇摆缩放、三瓣转圈、局部软体挤压、分段斜向色带，以及 O / + / × / > 符号序列。后续调整先看 `examples/brand-loading/` 的实际动效与中间帧；预览控制不进入正式加载画面，色场不扩展到编辑器画布背景。
- 字标随主题使用前景色，图形保持原有渐变；不能给标志额外加发光和悬浮位移。画布仍使用紧凑悬浮项目菜单，品牌不占据新的整行页头。
- 已有项目、素材库、登录 Cookie、服务配置等内部兼容标识继续沿用原存储协议，避免品牌改名导致历史数据丢失；历史版本说明和上游署名保留原名。

### 内容优先、克制中性

- 参照参考产品的创作工作台：深色、安静、紧凑，图片和视频承担主要视觉信息。不要用发光、彩色描边、厚阴影制造所谓高级感。
- 背景、卡片、边框和次要文字有适度层次，工具保持可发现，不能靠过低对比度隐藏必要信息。
- 使用 `src/index.css` 的语义 token，如 `bg-background`、`bg-card`、`bg-popover`、`text-foreground`、`text-muted-foreground`、`border-border`。
- 主题由 `applyTheme` 设置到 `document.documentElement`，Portal 浮层必须跟随深色、浅色及 Solarized，不能另起一套颜色。
- 强调色只用于有意义的状态。评论模式开启使用蓝色，不能把这个例外扩展成所有节点的蓝色光晕。
- 保留键盘 `focus-visible`。去掉廉价选中发光不等于删除键盘焦点提示。

### 对齐与文案

- 同一信息组共享对齐方式、左右边距和文字基线。空状态标题与提示统一居中，卡片标题与封面左边缘对齐。
- 空状态通常只保留一个标题和一条必要操作提示，例如“暂无模板”与“选中节点后，从右上角菜单保存。”
- 不在居中空状态下面另放左对齐说明，不同时重复“暂无”“如何创建”“如何使用”“存在哪里”。
- 标签、搜索框、标题能表达的信息，不再用重复标题、常驻说明或副标题复述。节点数量等细节放到模板预览里。
- 存储范围、模型限制等只在影响当前决策时放到合适的位置；实现细节留在文档，不作为常驻说明占画面。
- 说明不是操作的替代品，应能直接完成任务，不让用户先读长教程再寻找入口。

### 尺寸与状态稳定

- 按内容选择面板尺寸。图库需要大预览，不能继承普通菜单的窄宽度；也不能只放大空面板而继续保留图标占位。
- 图库顶部切换与搜索稳定，内容可滚动；保存、重命名等表单按需展开，不长期挤占预览面积。
- 圆角、图标、控件高度、内边距保持一致节奏。当前侧栏常用约 19px 图标和 36px 按钮，具体仍按内容验证。
- 悬浮只改变颜色、透明度或显示已有覆盖层，不改变宽高、边距、行高，不让下面内容跳动。
- 常用与窄视口都要检查：面板不越界，标题不压住操作，内容可滚动，主要操作可达。
- 滚动条参考无框样式：透明轨道、无箭头和轨道描边，6px 中性圆角滑块，颜色跟随深色、浅色和 Solarized。所有滚动条默认隐藏，鼠标移入对应滚动区域才显示，移出后隐藏；悬浮滑块时适度提高对比。显示与隐藏不改变内容宽高，保留滚轮、拖动、键盘及既有横向滚动行为，内容不溢出时不显示。

## 4. 已确认的画布与侧栏交互

### 画布与左下角控件

- **左键多选（2026-09-15）**：空白处按住左键拖动直接框选，移动超过 4px 才出现选框；Shift、Ctrl/⌘ 配合框选追加选择，配合节点点击增减选择。松手结算最后位置，缩放与画布偏移不能影响命中结果。
- 空格＋左键拖动或中键拖动平移画布并保留选择；空格松开或窗口失焦解除临时平移状态。输入、视频播放、浮层及评论操作保留各自事件，不被画布快捷键抢走。
- **右键拖动（2026-09-23）**：空白画布按住右键拖动同样平移并保留选择；移动不超过 4px 松开才打开新增菜单，拖动后不弹菜单。macOS/Linux 在按下时就派发 `contextmenu`，因此菜单统一在松开时出现；Windows 松开后才派发的那一次在拖动后被吞掉。节点、分组边框、控件上的右键仍是各自菜单，不参与平移；评论模式暂未启用右键平移。
- 多选显示临时边界、顶部公共工具栏（分组、保存为模板、下载选中素材）及右侧下游“＋”，收起单节点面板。拖动已选节点移动全部选中项；仅点击节点切换为单选，点击选区外空白或 Esc 取消选择。临时选区不保存为命名分组，只有明确分组操作才创建组关系。
- 普通鼠标滚轮上下平移画布；按住 **Control** 再滚动才缩放，并以光标位置为中心。阻止浏览器页面缩放抢走画布交互。
- 工具提示使用统一 Tooltip，鼠标点击或移出时关闭；键盘聚焦时仍可阅读并用 Esc 关闭。禁止用 `group-focus-within` 让点击后的提示长期滞留，也不为关闭提示强制移除按钮焦点。
- 输入区自身可滚动时不应误移画布；弹层输入期间，删除、撤销等快捷键不能误作用于背景节点。
- 左下角提供小地图、连线显示、网格吸附、重置视图和线性缩放。小地图支持开关、点击或拖动定位；隐藏连线只影响显示，不删除节点关系。
- 连线在滚动、拖动、缩放和任务状态更新时保持显示，不用整层隐藏作为性能降级。连线组件保持稳定身份，避免页面更新反复卸载 SVG；断开按钮按悬浮显示，单次点击只执行一次断开。
- 网格吸附表示拖动结束后对齐网格，多选节点保持相对位置；简短提示解释作用，不让用户猜。
- 节点拖动按按下位置计算累计位移，松手结算最后坐标；不能过滤掉慢速小位移或覆盖同一帧内的移动。一次拖动只产生一条撤销记录，单纯点击不产生记录；键盘删除使用最新快照，撤销后立即操作仍可撤销。Ctrl/⌘＋Shift＋Z 兼容浏览器上报的大写 Z。
- 右键未选中的节点时，菜单切换到该节点；右键多选集合中的节点时保留整个集合。媒体预览中的删除、撤销及画布快捷键不能穿透到背景；Esc 只关闭预览并保留节点选择。
- 重置视图表示居中显示全部节点，空画布恢复默认视图；不是清空、重排或重置节点参数。
- 缩放滑块线性改变比例，当前范围 20%–300%，显示实际比例。Ctrl/⌘ + `+` / `-` 缩放，Ctrl/⌘ + `0` 重置视图。
- 深色画布使用近黑背景和微弱点阵；点阵只辅助定位。当前 `.canvas-grid` 使用约 0.5px 细点，不再叠加大点或光晕。
- 节点选中使用细中性边框，相邻节点进一步弱化。低细节渲染也遵守同一规则，不能缩放后重新出现蓝色发光。
- 节点内容层圆角跟随外框，选中描边位于内容上方且不拦截鼠标；四角必须完整，不能被内容背景遮住，也不能裁切外部端口与工具栏。

### 工作流节点的内容层级

用户在 2026-09-08 对照“角色与场景提取”和参考产品视频节点指出：“我们的组件样式和参考产品比太呆了”。结合实机观察，节点改造遵守下面的结构要求；各类型的实现和验收状态见 [工作流改造实施进度](./workflow-implementation-status.md)，不能据此宣称全部节点已完成。

- 节点主体优先展示作品、文字或结构化结果。名称与类型图标放在主体上方的轻量标签区域，避免每个节点都套一条粗标题栏和分割线。
- **生成状态（2026-09-22）**：卡片与生成按钮共用该节点最新任务状态，切换节点或重新打开面板不能解除运行中的禁用状态。保留旧作品并再次生成时，明确显示“正在生成新图片／新视频”和“当前显示上次结果”；当前任务结果已成功写入后立即结束转圈，旧任务的迟到状态不能覆盖较新结果。待核对状态保留真实提示，不伪装成持续生成。
- **分镜模型与首帧（2026-09-22）**：分镜复用普通生成节点的模型菜单，展示模型名称和已声明能力，禁止展示 platform、渠道分组或内部 UUID。首帧／尾帧可按名称和缩略图选择画布已生成图片，保留本地上传与移除；保存具体图像快照及来源身份，刷新后恢复。提交需携带正确的首帧／尾帧用途；Seedance 首帧模式显示“比例跟随首帧”，不向供应商重复传入指定比例。
- **分镜视觉与编辑层级（2026-09-22）**：默认展示镜头缩略图、序号、名称、时长和真实状态，选中一镜才展开对应编辑区；不把全部镜头铺成长表单。节点名称与其他节点一样放在外侧轻量标签；编辑区区分首帧预览与生成结果，模型及规格集中底栏，规格收进同主题浮层。避免蓝色整行选中框、绿色大生成按钮和重复输出侧栏。表格作为独立编辑视图保留。缩略图按原比例完整显示，窄布局允许纵向滚动，不挤压主要操作。
- 清晰制作模板按“设定 → 分镜画面 → 镜头动画 → 剪辑”组织。图片阶段用“确认此画面”，视频阶段用“选为输出”；关联首帧按稳定镜头身份自动读取，缺少确认或连线时禁止误执行，不能靠同名节点制造关联假象。时间线必须读入全部确认镜头并按镜头身份去重，保留已有手工裁切和顺序。
- 将内容主体、上下文工具栏、生成配置分开。选中节点时显示相应编辑工具与输入面板；未选中时保留名称、内容、必要状态和可发现的连接入口，不让整张画布同时铺满表单。
- 模型、规格、参考素材和执行操作集中在紧凑配置区。不要在高大空卡片的顶部放一行全宽选择器，底部再放一条全宽高饱和按钮。不能为“显得活泼”增加彩色边框、发光或装饰性动效。
- 节点尺寸由内容类型决定：图像／视频尊重媒体比例，文字支持阅读编辑，提取／处理节点以结果列表和必要状态组织空间。没有结果时不为未来结果预留大块固定高度；出现结果后的尺寸变化也不能挤动其他节点。
- 提取节点不照搬视频的大图标占位。未接输入时提供明确连接入口；已接文字时展示来源和简短预览；处理中展示真实状态；完成后主体显示可继续使用的角色、场景条目。错误与缺少模型必须就地可理解。
- 文字、图片、视频生成复用同一面板；所有节点的模型入口使用锚定底栏的紧凑菜单。模型行按“名称＋实际能力标签”组织，当前项有中性底色和勾选；图片、视频、文字、音频、3D、提取和处理节点按实际操作能力筛选，不能把抠图、打光、数字人等模型混进普通生成列表。
- 无可用模型时在就地菜单显示当前节点的空状态。**平台创作界面不提供“管理模型”入口，管理员也通过独立管理后台维护配置。** 点击模型选择器只展开模型选择列表，不能打开预设、渠道或价格配置。未开放预设不冒充可用模型。能力标签与规格来自模型声明，未声明的不补造；切换模型同步有效参数、清除旧模型专属参数，保留提示词、素材与节点尺寸。
- 文字节点的标题和卡片空白处用于拖动，正文区域用于编辑和选字。正文编辑器按内容占高，不能用全高编辑区或容器级事件拦截吞掉整张卡片的拖拽；长文仍可通过标题移动。
- 图片生成结果主体单击只选中节点并展开工具与生成面板，双击才打开大图，避免选中操作被预览打断；键盘聚焦后 Enter／空格仍可预览。主体保留拖动，不能因整块主体使用 Button 而被通用交互控件拦截；拖动松手不打开预览，修饰键点击保留多选。媒体节点标题显示拖动光标；视频播放器保留播放和进度条操作，通过标题移动节点。验收包含单击选中、双击预览、关闭返回，以及从图片主体拖动单个节点及整个多选集合。
- 图片生成节点的空状态只显示图片占位，不在结果区放“上传图片”或“更换图片”入口，避免把上传内容直接写成生成结果。参考图通过“＋”或连线添加；本地文件通过新增菜单上传为素材节点。此规则也适用于角色／场景图片生成，已有素材上传能力和历史结果保留。
- **参考图选择与移除（2026-09-15）**：点击“＋”进入画布点选模式，顶部显示目标和退出入口；辅助列表提供名称搜索、缩略图、可用状态与已连接标记。无内容、生成中且无旧结果、失败及待核对的来源不可作为本次有效输入；已有旧结果可继续引用。已连接的无效来源提前显示原因并禁用生成，提交时仍需再次校验。不同输入端口分别判断已连接状态，保留首帧／尾帧等用途标签。
- 参考选择模式必须有就近退出路径：单击空白、当前目标、已连接参考或按 Esc／退出按钮，结束选择并恢复目标面板；点击不可用来源则退出模式并打开该来源的编辑面板，不创建无效连线。参考列表中的不可用项保留“查看节点”入口，不能只有禁用按钮。选择模式不拦截小地图和视图控件，目标节点消失时自动结束。不得因任务待核对而把整个画布留在点击拦截模式。
- 生成面板的参考项使用缩略图和实际节点名称，支持定位与移除。移除一个端口参考只断开对应连线；该来源已没有其他输入连线时，同步清除匹配的内联引用和旧参考图片。删除内联引用时同步断开该来源，避免画面上移除了引用、请求却继续带入；同一图片通过连线和内联引用重复选用时按用途去重。内联引用保存来源身份和内容快照，不因改名更新图片内容。
- 节点标题双击或键盘 Enter 就地改名，Enter／失焦保存，Esc 取消；单击与拖动仍遵守画布选择约定。名称同步到参考标签和有来源身份的内联引用；重命名可撤销，不改变内容、连线或模型。
- 裁剪先进入当前原图的临时编辑状态，默认保留全图，支持比例、边角调整、选区移动、重置、取消和确认。取消不新增节点；确认后创建连接到原图的独立图片结果，保留原图，一步撤销结果及连线。使用真实像素尺寸，禁止默认裁掉左上角 512×512。其他图片处理工具的临时状态迁移按后续验收单独推进。
- 图片工具栏以裁剪及当前可用的常用编辑为主，次要操作收进“更多”，保存素材、下载、全屏查看提供直接入口。模型处理入口按实际已开放能力显示。保存后进入“我的素材”并显示结果，重复保存同一图片不产生重复项。
- 大图显示真实尺寸和有来源的日期，缺失字段隐藏，不展示空的分隔符或内部任务 ID。画布打开单张结果时不显示无上下文的历史分组导航；保留同次多图结果的浏览和历史入口自身的导航。
- 生成面板与规格浮层保持统一的中性表面、圆角和控件节奏；模型与规格集中在底栏，规格显示当前值并一次展开画质、比例、时长，数量使用同主题菜单。禁止把每个参数拆成原生下拉框形成一排表单。
- **Seedream 规格面板（2026-09-15）**：按用户参考图，上方画质为等宽选项，下方比例为两行图标网格，自适应独立位于左侧；底栏用取景图标与“比例 · 画质”摘要。Seedream 5.0 Pro 开放 1K／1.5K／2K，以及自适应、1:1、9:16、16:9、3:4、4:3、3:2、2:3、5:4、4:5、21:9。自适应传分辨率档位，固定比例由后台按同一张映射表生成像素尺寸，费用预估使用同一规则；最终费用仍按实际输出核算。切换选项不生成、不关浮层、不改变提示词和已有图片。其他模型只展示各自已声明参数。GPT 渠道按下述用户授权开放，实际生成验收状态另行记录。
- **GPT Image 统一规格（2026-09-15）**：用户明确要求先开放三个 GPT Image 模型供其自行测试。GPT Image 2、2.5 Flare、2.5 Sunburst 复用 Seedream 的画质与比例面板及固定尺寸表（1K／1.5K／2K、10 种固定比例）；后台转换成 `size=宽x高`，不把 `ratio` 或 K 档位直接发往 GPT 接口。GPT 自适应按第一张参考图比例计算并限制在 1:3–3:1，无参考图按方形，始终保留所选像素档位；`quality` 固定为自动。旧节点的无效自动尺寸回到有效默认值，切换模型保留兼容规格、提示词与已有结果。渠道真实尺寸执行待用户生成验收，不能将控件验收写成接口验收。
- 参数浮层动效从触发入口轻微展开，使用柔和减速的淡入和短距离位移，关闭略快；不使用突然闪现、大幅缩放或弹跳。动效不改变布局、不延迟可操作时间，遵守减少动态效果的系统设置。
- 选中文字／图片／视频节点后，下方整块生成面板也需要柔和展开，不能只给规格小浮层加动效。面板定位完成后再淡入，输入和切换参数不重播；动画不能影响定位测量，避免重新引入面板跳动。
- 提示词区域只保留一句占位；已连接的参考文本按需查看，快捷输入帮助按需显示，不将来源正文、使用教程与占位提示重复堆叠。生成面板可以比节点更宽，窄视口自动收缩、换行，操作仍可达。
- `@` 引用与 `/` 指令候选在独立浮层中展开，不撑高生成面板、不抢输入焦点。选中、Esc 关闭与切换参数后可连续操作，不需要重新选中节点；拖动节点、分组、画布或调整节点大小时，编辑面板和参数浮层暂时收起；松手后恢复当前节点面板，保留输入与选中状态，参数小浮层保持关闭。只有点击空白处才取消选择。
- 配置面板始终锚定当前节点下方，不因空间不足翻到上方或侧面；打开时不重排节点，底部空间不足仅保持原缩放平移画布腾出位置，长面板内部滚动，不被节点的 `overflow-hidden` 裁掉。节点到面板的鼠标移动、键盘操作和中文输入应连续可用；编辑期间不能因轻微移出或焦点转移而关闭。
- Prompt 中 `@` 使用有身份和用途的内联引用，提交时实际解析所选内容，移除后不再消费；`/` 快捷指令写入可编辑要求，不另造节点或自动执行。当前引用保存选用时的内容快照。
- `@`／`/` 候选支持方向键、Enter／Tab 确认和 Esc 关闭；需要参考图的指令在没有可用参考时禁用并解释原因。选择指令仍只填入提示词，由用户明确生成。
- 节点悬浮、选中或菜单展开时，在外侧显示可用的圆形“＋”，移向入口的间隙仍可连续操作。右侧“＋”打开“引用该节点生成”，选择文字、图片、视频、音频或 3D 后创建并连接一个下游节点，不自动执行；左侧添加已有参考，原边缘端口仍支持拖线。按真实输入输出能力提供入口，不支持的生成类型禁用。
- 通过节点“＋”新增下游时保持当前缩放；位置冲突在来源附近避让，不能直接跳到整张画布最右侧。新节点已可见时不移动画布，出界时仅按原缩放平移到可见区域，不调用适配全景缩放。
- 多选创建下游时只创建一个目标并连接全部兼容来源；端口容量不足或存在不兼容来源时整体拒绝，不静默漏接、替换或运行。
- 视频目标编辑保留原片，明确区分目标帧、选区和替换图；重拍按片段组织，延长标明方向和时长。没有对应模型输入协议时保持不可执行。
- 多选时使用选择范围的公共工具，不叠出多个配置面板。缩放、平移和低细节渲染仍保留一致的标签、边框和端口语义。
- 节点框架与内容渲染在 `src/components/editor/` 复用，继续组合 shadcn/Radix 控件，不在每个 `App.jsx` 分支复制一套新样式。先对齐文字、图片／视频、提取三种代表结构，再推广到其余节点。

验收需在相同视口与画布缩放下比较两侧的未选中、选中、编辑、无输入、已有输入、处理中和有结果状态。用户的两张截图分别是处理节点和媒体节点，不能从截图显示尺寸推导固定像素值，也不能把两类节点做成完全相同的空卡片。

### 创作用户与管理后台的边界（2026-09-14）

- **渠道凭据（2026-09-22）**：管理员在渠道页直接填写 API 地址和 API Key，支持连接测试、保存与替换，不要求编辑服务器环境文件。保存后只显示“已配置”，编辑时密钥输入为空，留空保留原值；不能把脱敏占位符作为真实密钥提交。连接测试明确区分认证、网络、接口不支持和成功，不能把可连接等同于生成权限或余额可用。
- 用户明确否定“把简陋模型管理抽屉暴露在创作界面”。模型管理必须是 `/admin/models` 的独立完整页面，具备表格、搜索、筛选、状态、编辑和按需打开的预设导入。渠道、价格、用户、成本和审计各有后台页面；不能把后台菜单逐项堆进画布头像菜单。
- 普通用户在节点里只看到模型名、真实能力、当前选择和生成参数，不看到供应商接口、模型 ID、API 预设、凭据引用、渠道成本或配置 JSON。图片、视频、文本等模型按操作能力筛选；未接入模型不能为凑齐参考产品菜单而假装可用。
- 同系列模型的英文后缀不能作为唯一选型依据。模型菜单保留必要中文特点，例如 Flare 的“快速生成”、Sunburst 的“精细编辑”；标签来自后台声明和已接入能力，不仅根据英文名字猜测，也不把特点宣传成所有任务的性能保证。
- **模型菜单密度（2026-09-15）**：参照用户截图，使用约 280px 宽的中性菜单，优先向上展开，空间不足交给 Radix 避让。每项名称与选中勾为第一层，规格和必要特点为第二层，最多两项；移除重复“图片参考／图片编辑”等标签，不常驻整段用途说明。当前项与悬浮项使用不同深浅的底色，条目之间保留间隔，不能连成两块厚卡片；不虚构 NEW、4K 或未开放能力。
- 参照参考产品当前实机：模型紧凑菜单锚定底栏；每项为图标、名称、能力标签和选中勾。规格另用小浮层，数量独立选择，生成按钮独立。账号头像在左侧栏末端；普通用户菜单包含个人工作空间、使用记录、账户管理和退出。不要展示虚构余额、会员、团队或充值功能。
- 创作端移除模型设置、预设导入、渠道及价格入口；管理员头像只保留一个独立“管理后台”入口。旧 `platform:panel` 事件不能打开任何管理界面。普通用户直接访问 `/admin/*` 要显示拒绝访问，后台 API 同时校验管理员角色。
- 工作空间项目图库右上角也必须显示同一账号菜单，支持直接退出登录；不能要求用户先返回画布才能找到账户操作。
- 验收必须新建或使用真实普通用户账号登录，检查菜单、模型筛选、规格切换、项目隔离和后台 403；不能只用管理员界面推断普通用户体验。参考实机细节记录在 [参考产品模型对照](./research/reference-model-catalog-2026-09-08.md) 的 2026-09-14 补充中。

### 菜单与浮动侧栏

- 画布顶部使用紧凑的悬浮项目菜单，右侧只保留必要的快捷操作和账号入口，不再占据整行固定高度。新建、重命名、导入导出、主题、语言、性能选项收进项目菜单，不重复显示项目名。
- **以工作空间为中心（2026-09-23）**：用户指出“整个平台以工作台为中心，而不是画布为中心”。登录后（本地模式启动后）首页 `/` 是工作空间项目图库；画布只是打开某个项目后的编辑页，地址为 `/canvas/<项目 ID>`，由地址决定打开哪个项目，不再用“上次项目”自动进入画布。项目不存在、已删除或不属于当前账号时回到工作空间并提示。画布项目菜单的“返回工作空间”和账号菜单的“工作空间”先保存再离开；“新建项目”回到工作空间并打开新建对话框。编辑器按页面固定项目存储前缀，进出画布都整页跳转，不在同一页面切换项目。工作空间沿用在画布里最后选择的主题。
- **工作空间版式（2026-09-23）**：按用户提供的参考项目页，顶部为品牌、居中的“工作空间”胶囊标题和账号胶囊；内容区左侧“我的项目”下划线标签，右侧依次为搜索、排序菜单、网格／列表切换、新建项目。网格首位是“新建项目”卡，项目卡为 4:3 封面＋加粗名称＋“编辑于 N 天前”，整卡可打开，更多操作收在封面右上角悬浮显示的 ⋮ 菜单（触屏常显），包含打开、重命名、复制项目和删除。删除须经确认弹窗（默认焦点在“取消”）；平台模式在后台归档项目以保留使用记录，并清理本浏览器中该项目的画布数据；本地默认项目只清理画布内容，不动浏览器级设置。参考页的团队项目、文件夹、分享链接、移动至团队等功能尚未实现，不做成空壳入口。
- **项目多选删除（2026-09-23）**：封面左上角复选框与 ⋮ 对称，悬浮或键盘聚焦时显示（触屏常显）。有选中项后全部复选框常显，整卡点击改为切换选择，⋮ 隐藏但不改变布局；Shift 点击按当前排序选择区间，Ctrl/⌘ 点击直接进入选择。选中用细中性边框，底部居中浮出“已选择 N 个项目 · 全选／取消全选 · 删除 · ×”，Esc 或 × 取消选择。选择只作用于当前搜索结果，修改搜索即清空选择。批量删除与单个删除共用确认弹窗（默认焦点在“取消”），列出前三个项目名；逐个删除，失败项留在弹窗和选择中说明原因，可重试，已删除的项目立即移出图库。
- 新建项目不能清空当前项目；切换前保存当前快照，读取目标项目独立的存储。保存失败时留在当前项目并说明失败，不能继续切换。

- 新增菜单由**右键点击空白画布**触发，不再占用左键双击。节点、输入框和已有菜单保留自己的上下文。
- 菜单不能因轻微鼠标移动消失，父菜单进入子菜单必须连续可用；不使用 `onMouseLeave` 直接关闭。
- 新增菜单按上传、素材、创作节点、辅助工具、撤销/重做/粘贴等组织，不堆成无分组长列表。
- 浮动侧栏覆盖画布，不挤压、平移或缩小画布。左侧各面板之间切换互斥；右侧 AI 创作面板使用独立开关状态，左侧导航的打开、切换和关闭均不改变它的显隐。
- 新增、搜索、素材、模板、历史、更多，每个入口都要走通结果：搜索可以定位，素材可以放入画布，历史能预览或复用，不能只有空壳。
- 搜索、分类、展开/收起不互相重置上下文；关闭详情后返回原筛选位置并恢复入口焦点。

### AI 对话与画布引用（2026-09-23）

- 视频时长选项保持单行横向滚动，点击可视区域靠右的秒数后平滑前移露出后续选项，靠左时可反向返回；打开时已选值可见。时长行始终隐藏滚动条（包括悬浮时），保留横向滚动能力。复用 ScrollArea 与 Button，不将逐秒选项排成宫格；遵守减少动态效果设置。

- **Seedance 2.5 视频规格（2026-10-20）**：清晰度为 480P、720P、1080P；比例为 16:9、4:3、1:1、3:4、9:16、21:9；时长 4–15 秒逐秒可选。“使用首尾帧”及连接入口置于规格浮层最上方。前后端参数定义同步，其他模型仍按各自声明能力展示。

- **助手模型选择（2026-10-20）**：新对话底部模型入口使用 shadcn DropdownMenu 与单选菜单项，向上展开，当前项显示勾选；长列表在可用高度内滚动。选择只更新待发送模型，不自动发送消息；已有对话沿用原模型。

- **引用选择与预览（2026-10-20）**：AI 面板打开时，普通点击画布节点将本条消息引用替换为该单个节点；拖动、修饰键多选和节点操作按钮不触发此替换。“从画布添加”进入多选点选模式，逐个添加或取消。两种入口均在输入框内部上方展示统一的矩形缩略按钮：图片／视频显示缩略画面，文本显示文本图标，不再显示“当前选区”或带名称的长标签。悬浮或键盘聚焦时在上方显示内容与名称预览，右上角显示移除叉号；移向叉号即关闭预览。至少两个引用时在队列末尾显示清除全部按钮；移除只影响消息引用，不删除画布节点。

- **默认展开（2026-10-20）**：每次进入或刷新平台画布时，AI 创作面板默认展开；点击右上角叉号后收起为右下角圆球按钮，点击圆球可重新展开。关闭状态不跨页面记忆，当前页面内不因数据更新而自动重开；显隐仅由 AI 创作按钮和面板叉号控制，可与左侧工作台面板同时打开。

- 引用媒体预览的展示区在异步加载前后保持尺寸稳定；预览内容及 Radix 定位外层均不拦截鼠标，避免图片加载重新定位时遮住入口、反复触发移入移出造成闪烁。验收须包含鼠标停留在图片缩略按钮上，而不只检查键盘展开。

- **历史对话管理（2026-10-20）**：历史选择使用 shadcn Popover 组合列表，不使用原生 Select。顶部“新建对话”带加号；每行右侧默认显示修改时间，悬浮或键盘聚焦后原位切换为编辑、删除按钮，触屏常显操作。编辑时隐藏操作按钮，名称变为自动选中的输入框；Enter（排除中文输入法组合输入）或失焦保存，Esc 取消，保存失败保留输入并显示原因。手工标题不得被自动概括覆盖。删除当前对话后回到新对话，保留画布作品及计费记录；执行中的对话须先停止。改名、删除结果持久化并按账号和项目隔离。

- **历史对话入口（2026-10-19）**：对话选择框紧邻“AI 创作”标题，使用同一行剩余宽度，右边止于新建对话加号前；长标题省略，窄屏不挤压新建与关闭按钮。历史标题概括用户首次输入的主题与目标，不直接照抄或截取原文；后续消息不改变标题。

- **完整制作工作流（2026-09-29）**：用户要求从参考产品的实际工作流提炼方法并同步修复。助手先读制作方法库，再按“剧本/共享设定 → 人物与场景参考 → 静态分镜 → 动态镜头 → 剪辑”建立真实数据依赖，不把堆放节点当作工作流完成。参考与镜头规则实际连入消费者；三视图是身份参考，剧情首帧是对应镜头画面。视频分镜按稳定镜头身份绑定已确认图片，选片进入时间线；结构完整、等待素材、已提交、已完成分别报告。没有文生图模型不能成为省略文字创作或连线的理由。具体观察与适配见 [参考产品制作方法](./research/reference-workflow-methodology-2026-09-29.md)。
- 工作流通过结构化参数原子创建节点、连线和命名分组，新节点间用临时 key 引用，完成前检查孤立节点、循环、端口容量与镜头绑定。布局按列内最大宽度和各节点实际高度分配空间；调整已有流程时保留正文、镜头、参考、参数和作品。助手方法库与公共模板使用同一原创蓝图，模板应用仍不自动生成。

- 平台 AI 对话使用右下角约 52px 的常驻圆球入口，复用 Elren 已有的流动色场。配色以蓝、海蓝和柔粉为主，避免刺眼的霓虹青紫；球面以局部高光和边缘明暗呈现体积，不叠加独立的大圆形内泡或均匀描边。参考图只用于理解光学层次，不照搬内部轮廓。每次悬浮或键盘聚焦时立即有一次可见的玻璃高光扫过，随后球内色流持续游动，不改变球体尺寸；面板从右下方短距离柔和展开，不延迟操作。所有新增动效遵守减少动态效果设置。关闭面板后恢复小球，不把主入口藏在“更多”菜单。桌面面板默认宽约 480px，窄屏按视口收缩；打开不挤压画布，可与左侧工作台侧栏共存，页头操作不得覆盖助手按钮。
- 助手输出按内容排版：标题、强调、列表、引用、表格与代码块正确渲染，不把原始 `**`、`##` 当成正文展示。修复外层 Markdown 围栏或双重转义时保留代码原文；内容需清理，不加载模型返回的跟踪图片、脚本或任意布局样式。
- 已完成的工具步骤收进可展开的“操作记录”，不在对话末尾重复堆叠相同成功卡片；需要用户确认的生成操作仍直接显示。
- 输入区提供明确的“从画布添加”入口。开启后点选节点加入本条消息的引用，再点同一节点或点击引用上的 × 移除。引用显示真实缩略图或对应类型图标及名称；不靠当前选区代替持久的消息引用。
- 点选期间不拖动节点、不弹出媒体预览、不自动连线或生成。退出按钮、Esc、点击空白或关闭面板退出点选，保留已添加的草稿引用；视图控件仍可用。
- 发送时保存节点身份和内容快照，引用优先于随后变化的临时选区；删除的来源明确提示，不能静默漏发。历史消息保留引用名称；引用本身不授予额外权限，也不代表当前文字模型已经理解图像像素。

### 评论模式（批注）

- 侧栏评论按钮是**模式开关**，不是评论列表入口或居中表单入口。
- 开启后按钮变蓝、光标变气泡；点击画布，就在落点附近展开小输入框。
- 使用 `Popover` 虚拟锚点绑定画布坐标；缩放、移动后输入框和评论点仍跟随同一落点。
- 当前输入框约 300px 宽，文本自适应高度，最多 200 字，显示字数和提交状态。
- Enter 提交，Shift+Enter 换行，Esc 退出；中文输入法组合输入期间不误提交。
- 已保存气泡可原地打开、编辑、删除。模式内阻止误拖节点、误运行生成，已有评论点和视图工具仍可用。

### 模板图库

- 默认宽 560px，桌面三列方形封面；右上角展开至 1040px，宽屏四列，窄屏按视口收缩。这是模板库基线，不是所有侧栏的固定尺寸。
- 顶部直接放“公共模板 / 我的模板”、搜索、更多、展开、关闭；保存选中节点和导入放在更多菜单，保存表单按需出现。当前公共模板是所有用户可用的内置目录，不宣称已接入公共投稿市场。
- **内置模板必须有封面。** 使用与用途相关的实际示例图，不用巨大文件/布局图标充当永久封面。
- 个人模板优先使用已保存封面或节点媒体；无媒体或加载失败时展示实际节点结构，避免破图或伪造效果图。
- 图片按原比例展示；确需裁切时检查主体完整性。分镜可组合多张镜头图。使用轻量封面资源，不把多张原始大图直接内嵌进单文件构建。
- **封面和标题结构分离。** 不把图片、标题、说明整体包进有背景悬浮的 Button；标题区保持透明，不随封面变色。
- 悬浮或键盘聚焦时，只在封面边界内出现遮罩和“查看 / 应用”，不扩展到标题、不拉长卡片；触屏也能访问操作。
- “查看”打开只读封面及真实节点/连线预览，不插入节点；“应用”才插入画布。预览里的“应用到画布”走同一插入路径。
- 插入生成新 ID，保留内部连线和相对布局，选中并定位结果；不能自动运行生成或消费模型额度。
- 图库只保留必要标题，数量与流程说明进入详情；个人模板重命名、移除收在管理菜单。
- 保存入口直接展开“我的模板”中的名称与封面编辑，分组保存预填组名；保存成功后保持“我的模板”、清除旧搜索、显示新卡片，不能只打开图库让用户再找一次保存。

### 命名分组

- 框选节点后通过右键菜单或 Ctrl/⌘ + G 创建命名分组，显示明确但克制的边界和组名。公共模板插入后自动成为命名分组。
- 拖动组标题或边框空白处移动整组，保持内部布局与连线，不能带走未加入组的节点。单个节点仍可独立编辑。
- 组菜单提供重命名、复制整组、保存到我的模板、解除分组。解除只移除分组关系，不删除内容。
- 复制必须生成独立的组 ID、节点 ID 和内部连线；插入或复制避让已有节点，不能把无关内容围进新边界。
- 分组信息随节点序列化，支持撤销、刷新、项目导入导出、模板保存与复用。不能只画一个不随内容保存的装饰框。

## 6. 行为、数据与组件契约

- 页面入口连接真实能力；不可用时按上下文隐藏或明确禁用，不用成功 toast 掩盖未实现。
- 区分“查看/执行”“隐藏/删除”“重置视图/清空项目”，不能在外观调整中改变数据或触发生成。
- 表单按钮明确 `type="submit"` 或 `type="button"`，禁止嵌套 Button。开关用 `onCheckedChange`，Slider 使用数组值，NativeSelect 保留 FormData 契约。
- 模态弹层提供标题、焦点约束和返回；非模态就地编辑不遮断整张画布。处理 Portal 事件冒泡，避免快捷键操作背景。
- 规格等非模态浮层首次点击外部即收起，包含提示词区、其他控件和画布空白；点击浮层内选项或嵌套菜单保持正常操作，Esc 可关闭。画布与 Portal 面板拦截鼠标事件时，通过 Radix 的 dismissable surface 接口兼容外部关闭，不能要求用户再次点击入口。
- 覆盖默认、悬浮、键盘聚焦、按下、禁用，以及业务需要的加载、失败、空状态。没有实际行为的状态不要伪造。
- 当前个人素材/模板使用浏览器 IndexedDB，按账号隔离、同账号跨项目复用，异步保存检查账号切换。不得宣传成云端共享或多人协作。
- 当前评论沿项目存储，示例封面不是生成节点运行结果。后续实现云端库或团队评论后，再同步更新能力说明。

## 7. 交付前如何验收

**构建成功不代表视觉和交互通过。用户最常指出的问题发生在悬浮、模式切换与空状态。**

按改动范围检查，不机械扩大全套测试：

1. 使用用户现有系统 Chrome 和已运行的开发服务，优先复用当前页，不主动启动新服务或另开内置浏览器。
2. 对照参考检查实际尺寸、封面加载、对齐、边框、点阵、标题和留白。必须看默认与悬浮，不能只读 DOM。
3. 走完本次改变的路径：入口 → 展开 → 选择/编辑 → 结果 → 关闭/返回；确认不误触背景、不误写数据。
4. 检查相关键盘和焦点；评论检查 IME，菜单检查子菜单路径，图库检查展开/收起和筛选保留。
5. 媒体界面检查有封面、无媒体、加载失败；失败不破坏操作。检查资源体积，避免拖慢加载。
6. 有业务或交互风险的修改运行针对性测试及必要构建；简单文案、对齐修改不写复述实现的测试。
7. 报告区分“代码已改”“测试通过”“浏览器验证”“仍未验证”，不能把未验证上传、拖放、真实模型运行说成已完成。

按需选择现有验证入口：

- `npm run build`：生产单文件构建。
- `tests/ui-governance.test.js`：组件引用和业务边界。

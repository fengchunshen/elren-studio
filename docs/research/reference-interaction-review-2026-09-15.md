# 参考产品交互复核与 Elren 修改建议（2026-09-15）

## 结论

优先改善“选择哪张参考图 → 在原图上编辑 → 查看并保存结果”这条路径。当前主要差距是操作对象难辨认、编辑过早创建节点、结果信息不完整。不要再把已经实现的单击选中、双击预览、`@` 引用、`/` 提示词和多选下游列为缺失功能。

下表记录原始调研证据；用户随后确认实施，当前进展见文末“确认后实施”。统一交互规范仍以 [frontend-ui.md](../frontend-ui.md) 为准。

## 方法与范围

- 复用系统 Chrome 的参考产品核对画布和本地 `localhost:8081` 的「文生图 → 图片编辑测试」项目。
- 参考产品实机覆盖：空图片节点、选中状态、面板添加参考、全局上传菜单、已有图片工具栏、裁剪进入与取消、图片更多菜单、图片右键菜单、全屏查看。
- 本地实机覆盖：空节点、已有结果、添加参考列表、图片工具栏、裁剪入口、撤销临时节点、双击预览与 Esc 返回。原项目四个图片节点及两张生成结果保留。
- 本轮没有运行参考产品付费生成，没有提交裁剪结果；本地没有新发起模型任务。图片工具的模型执行结果、视频成片编辑、音频生成、团队协作和所有尺寸/主题不在本轮实跑范围。
- 官方文档用于补充操作契约；文档、页面与本地源码证据分开标记。不同模型、节点来源与账户可能呈现不同入口。

## 已完成：图片生成结果区不再承担上传

- 普通、角色和场景图片生成节点不再传入写入 `node.content` 的 `onFile` 回调，移除中央“上传图片”和结果右上角“更换图片”，同时不再为这些节点挂载相应文件输入框。
- 新增菜单的上传、已有图片素材节点、视频上传、生成结果、连线和历史数据保留。
- 拖图片到普通图片生成节点的现有路径是创建并连接参考素材，见 `handleGenNodeDrop`，没有改成覆盖结果。
- Chrome 已检查无结果节点、超时节点和两张已有结果，均没有上述上传/更换入口。单击选中与双击预览仍可用。
- 针对性回归：`tests/canvas-selection.test.jsx -t 'drags generated images'` 通过（1 项，9 项未运行），覆盖图片不再提供更换/文件输入、视频更换保留、拖动、多选及预览。生产构建和 `git diff --check` 通过；没有声称整套测试通过。

## 其他可学习点与边界

1. **图片比例**：本地正方形生成结果仍装在横向卡片里，左右留宽边。可研究首次出图按比例适配节点，之后尊重用户手动调整的尺寸；不是无条件在每次生成后改变布局。
2. **非模态操作**：参考点选、裁剪这类任务围绕当前作品展开，独立配置/表单才使用 Dialog。这是本轮最值得学习的组织方式。
3. **保留已有能力**：多选拖动、下游连接、参数浮层、`@`、`/` 已实现；之前 9 月 9 日审查中的对应“缺失”条目不再适合作为当前待办。现有 Seedream 生成→编辑成功样本也证明当前普通图片链路可执行。
4. **不机械复制**：参考产品的 3D 来源图片仍有“替换”，音频节点可见“上传”。本轮结论限定为图片生成结果区，不能推广成全站禁止上传。官方文档中的双击空白新增、指令自动执行，也不能覆盖用户已确认的本地右键新增和显式生成约定。
5. **模型能力不是按钮数量**：参考产品展示的质量、分辨率、数量和特定工具必须对应我们真实后端能力；本轮没有据此扩充供应商参数或发起付费测试。

## 建议实施顺序

1. 参考图识别与状态：缩略图/画布点选、来源命名、空源反馈。
2. 编辑临时状态：先做裁剪代表流程，明确确认、取消、撤销及原图保留，再推广到扩图/蒙版。
3. 结果操作与信息：工具栏收纳、下载/保存/全屏、真实尺寸与日期。
4. 引用输入一致性和键盘补齐；最后处理比例、自适应与其他媒体类型。

每阶段走真实 Chrome 路径验证，不把组件单测或构建通过当作交互完成。未验证的供应商执行继续单独标记。

## 确认后实施（2026-09-15）

- 参考选择改为画布点选模式，并提供搜索、缩略图、状态及已连接标记的辅助列表。空参考提前解释并拦截生成，原提交前校验保留。
- 节点标题就地编辑；名称同步到参考标签和具有来源身份的内联引用。参考项增加移除，连线与内联引用的删除保持一致；相同 URL、媒体类型和用途去重，不混淆首尾帧。
- 裁剪采用临时原图编辑，默认全图，支持比例、拖动边角、移动选区、重置、取消和确认。确认后生成独立图片节点及连线，保留原图并支持一次撤销。后续扩图／蒙版等工具仍使用原处理路径，本次没有宣布完成它们的迁移。
- 工具栏分为常用编辑、更多和保存／下载／全屏。仅展示已开放的模型操作；素材保存后进入“我的素材”，同图重复保存去重。
- 大图接入真实尺寸、日期与标题，取消无上下文的画布历史分组箭头。候选新增 Tab 确认及九宫格缺参考时的提示，不自动调用模型。
- 新裁剪结果按比例放置并限制节点显示尺寸；未批量修改历史节点尺寸，既有媒体和项目保留。

### 待核对节点“卡死”返工

- 用户再次反馈后，在当前 Chrome 发现画布实际停留在“为珊瑚橙改色选择参考”模式。不可用来源只弹提示，模式继续拦截所有节点操作；单击空白还会清除选择并隐藏面板，造成无法继续的观感。
- 修复：空白、目标节点、已连接来源、Esc 和退出按钮统一返回目标编辑；不可用来源则结束选择并打开来源面板。列表项可查看，不新增无效参考。小地图与视图控件保留操作，目标节点消失时结束模式。
- 同一待核对节点已通过 Chrome 点击验证：选择模式消失，提示词与模型选择面板恢复。未重发模型任务，未将未知结果改为失败或成功。
- 新增真实事件回归覆盖上述退出路径、视图控件及重复连接；任务核对状态和安全轮询相关测试保留。

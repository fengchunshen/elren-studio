# 画布交互检查（2026-09-15）

## 已确认并修复

| 问题 | 原因与修复 | 验证 |
| --- | --- | --- |
| 慢速拖动不跟手，快速松手漏掉最后位置 | 单次 `movementX/Y` 的小位移被过滤，同一动画帧的增量被覆盖。改为从按下点计算累计位移，松手结算最终坐标。 | 回归测试覆盖连续 0.5px 移动和末帧；Chrome 普通拖动通过。 |
| 拖动不能撤销 | 单节点、多选拖动未保存历史。第一次实际移动时记录一次快照，单纯点击不记录。 | 回归测试；Chrome 一步撤销与重做通过。 |
| Shift＋⌘＋Z 重做失效 | 只匹配小写 `z`，浏览器可上报大写 `Z`。改为大小写无关匹配。 | 回归测试；Chrome 快捷键通过。 |
| 键盘删除后撤销恢复了旧布局 | 全局删除监听保留了旧快照函数。改为通过 ref 读取最新快照，同时去掉撤销后 100ms 内不记录新操作的时间窗口。 | 测试先复现恢复到 100px 而非最新 120px，再验证修复及撤销后立即拖动。未在用户真实节点上做破坏性复现。 |
| 媒体预览快捷键穿透 | 预览未被画布快捷键识别为独立交互区域，Delete 删除背景节点，Esc 清掉背景选择。隔离预览与播放器快捷键，并保留预览自己的关闭、导航。 | Delete 穿透用隔离数据测试；Chrome 预览关闭与保留选择通过。 |
| 右键菜单作用于错误节点 | 右键只沿用已有选择。改为右键未选节点时切换目标，右键多选集合内节点时保留集合。 | 回归测试；Chrome 从图片切到视频右键菜单通过。 |
| “＋”新增节点与邻居重叠 | 创建路径未传来源，绕过了仅在有来源时执行的位置避让。补用附近避让算法，不改变当前连接策略和缩放。 | 测试先复现与已有节点同为 `(540,100)`，修复后新节点位于 `(540,480)`，缩放保持 120%。避让分支未完成 Chrome 验收。 |

## 验证结果与边界

- `tests/canvas-selection.test.jsx`：10/10 通过。
- 原有编辑器冒烟检查：修正了不真实的几何模拟（原先节点、浮层均被模拟为整屏大小，导致自动平移把节点移出视口）；常规 6 项通过，下游创建、连线、撤销专项通过，避让专项通过。批量运行仍出现过超时，不将分项通过表述为整套稳定通过。
- 浮层、提示、评论、生成参数、引用菜单、模板等组件扩展检查：首次 15/18 通过；对相关文件串行复查 6/9 通过，仍有提示键盘操作、模型键盘选择、平台参数切换 3 项超时，不能仅据此认定为产品缺陷或已通过。
- 生产构建、改动文件空白检查通过。
- Chrome 已检查拖动、撤销、重做、预览关闭、右键目标切换、下游创建/连线/撤销、模型与规格菜单开关。临时节点已撤销，原 2 个节点及 1 条连线、原布局已恢复。
- 随后现有 Chrome 被切换到另一个正在生成的验收项目，因此停止继续操作；没有触发模型生成。新增避让分支的浏览器验收仍待补充。
- 过程中出现过开发热更新后项目上下文为空的启动异常，刷新后恢复；后续热更新曾正常恢复。该开发态问题尚未独立定位，不计入已修复项。
- 本轮范围为画布常用路径及相关组件，并非所有节点类型、所有主题、所有屏幕尺寸的完整验收。
